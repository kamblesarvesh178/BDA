# Big Data Analytics (BDA)

This repository contains code, notebooks, and resources for the **Big Data Analytics** course/project under the **Artificial Intelligence and Data Science** branch. It includes practical implementations using Python and Jupyter Notebooks, covering MongoDB operations, word frequency analysis, matrix computations, grading systems, and dashboard visualizations.

## 📁 Repository Structure

```
BDA/
├── 1Mongo.txt               # MongoDB operations
├── 2wordfreq.py            # Word frequency analysis
├── 3Matrix.py              # Matrix operations
├── 4Grade.py               # Student grading system
├── 5_dashboard.pbix        # Power BI dashboard
├── BDA2.txt                # Additional BDA notes/code
├── HmapReduceGrade.ipynb   # MapReduce for grading
├── Hmatrix.ipynb           # Matrix operations in notebook
├── grade.csv               # Sample dataset for grading
```

## 🚀 Technologies Used

- **Python**
- **Jupyter Notebook**
- **MongoDB**
- **Power BI**
- **MapReduce Concepts**

## 📌 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/kamblesarvesh178/BDA.git
   ```
2. Open `.py` or `.ipynb` files in your preferred IDE or Jupyter environment.
3. Use `grade.csv` as input for grading-related scripts.
4. Open `5_dashboard.pbix` in Power BI to view the dashboard.

## 📚 Topics Covered

- **MongoDB** – Basic operations and queries.

- **Matrix Computation** – Mathematical operations on matrices.
- **Grading System** – Automated grade calculation.
- **MapReduce** – Distributed data processing.
- **Power BI** – Data visualization and dashboarding.
